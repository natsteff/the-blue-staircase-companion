# Read *The Last Witness* on iPhone, iPad, or Kindle

> **Working draft:** The novel is unfinished. The current v02 preview contains Chapters 1–2 of 24 planned chapters. Later drafts may revise earlier chapters. The EPUB is a book file; **Sally's Detective Notebook** is a separate optional web app.

## Quick start: iPhone

1. Download the [Working Draft v02 EPUB](https://natsteff.github.io/the-last-witness-companion/books/The_Last_Witness_-_Working_Draft_v02.epub). The [project README](../README.md#read-the-working-draft) also has the current download.
2. If Safari displays a download arrow, tap it to find the downloaded EPUB. Otherwise open the **Files** app, choose **Browse → Downloads** (often under **iCloud Drive** or **On My iPhone**), and locate the `.epub` file. The exact download location depends on Safari settings.
3. In **Files**, touch and hold the EPUB and choose **Share** (or open the file and tap the Share icon). Choose your reading app:
   - **Books** to read in Apple Books.
   - **Kindle** to import using Amazon's Send to Kindle workflow.
4. Open the chosen reading app and locate the imported book in its library. Importing into one app does **not** automatically add it to the other.

## Option A: Apple Books

1. Install/open **Apple Books** on your iPhone if necessary.
2. In **Files**, locate the downloaded `.epub`.
3. Tap **Share** and select **Books**. If Books is not visible, scroll the share-app row, tap **More**, and look for Books. On some iOS versions, simply tapping the EPUB in Files opens it in Books or offers an **Open in Books** option.
4. Apple Books should import the EPUB and open it. If it does not, open **Books → Library** and search for **The Last Witness** or inspect recent additions.
5. Use the book's table of contents to jump to the chapter you want. The book may sync between Apple devices using the same Apple Account if Books/iCloud syncing is enabled; this is separate from Kindle.

### If Apple Books does not appear or the file will not open

- Confirm the file ends in `.epub` and has fully downloaded; a `.zip`, `.html`, or partial download is not the EPUB.
- In the iOS share sheet choose **More** to find Books. If needed, open the Books app once and try again.
- Retry by tapping the EPUB directly in Files. Update iOS/Books if the EPUB still fails to import.
- Re-download the latest EPUB if the file seems damaged. If the problem persists, report your device/iOS version and the book's working-draft version in a GitHub Issue.

## Option B: Amazon Kindle on iPhone

1. Install the **Kindle** app and sign in to the **Amazon account whose Kindle library should receive the book**.
2. Download the EPUB and locate it in **Files → Downloads**.
3. Touch and hold the EPUB, tap **Share**, then select **Kindle**. If Kindle is not listed, choose **More** in the share sheet; ensure the Kindle app is installed and has been opened at least once.
4. The **Send to Kindle** screen may show the **filename** as the title and an account-based default author rather than the EPUB's embedded metadata. Before tapping **Send**, edit the fields:
   - **Title:** `The Last Witness - Working Draft (Chapters 1-2)`
   - **Author:** `Nate and OpenAI`
   - Turn **Add to your library** **on** if offered, so the document is stored in your Kindle library rather than sent only to a particular device.
5. Tap **Send** and wait for processing. Open the Kindle app's **Library**. Use **All** rather than only **Downloaded** if necessary, refresh/sync, and search for **The Last Witness**. Processing and delivery may take a few minutes.
6. If you have a separate physical Kindle signed into the **same Amazon account**, sync that Kindle and look in its library. It may need Wi-Fi to download the personal document.

**Important:** An EPUB imported through Send to Kindle is a **personal document**, not a purchased Kindle book. Amazon Family/Household book sharing should **not** be relied on to make it appear in a family member's separate account. To let another person read the draft, have them download the EPUB and send it to **their own** Kindle account, or use Apple Books on their device.

### Alternative: Send to Kindle website

If the iPhone share-sheet import fails, open [amazon.com/sendtokindle](https://www.amazon.com/sendtokindle) in a browser, sign in to the intended Amazon account, and upload the EPUB. Follow the site's current prompts. Availability of title/author editing may differ from the iOS share flow; verify the resulting library entry.

### Kindle troubleshooting

- **Not in Library:** Confirm the Send to Kindle operation completed; check the correct Amazon account, select **All**, refresh/sync, allow processing time, and check Wi-Fi. Search both the title and the original filename.
- **Wrong title or author:** Correct the fields on the iPhone Send to Kindle screen **before** sending. EPUB metadata alone may not populate these fields in that workflow. If already imported incorrectly, remove the incorrect personal document from your library and send it again with the desired fields, taking care not to delete other documents.
- **Kindle share option missing:** Install/update/open Kindle, then use **Share → More** from Files. Use the Send to Kindle website if necessary.
- **EPUB rejected:** Re-download the file, verify it is an actual `.epub`, and try the website upload. Report the version and error message if it still fails.
- **Visible on your Kindle but not someone else's:** Check whether the other device uses a **different Amazon account**. Personal documents generally need to be sent to each reader's own account; Family Library sharing is not a reliable solution.
- **Old draft still appears:** Each new working draft is a separate document and may be imported as a new library item. Remove older drafts manually if you no longer need them. Kindle reading position and annotations should not be assumed to transfer between draft versions.

## Companion notebook and updates

Open [Sally's Detective Notebook](https://natsteff.github.io/the-last-witness-companion/) separately in Safari. Choose the chapter you have **finished** to review clues, hear Spanish pronunciation, and track vocabulary. On iPhone, Safari's **Share → Add to Home Screen** can install it as **TLW Notebook**. It is not required to read the EPUB.

When a new cumulative working draft is published, download the new EPUB and import it again. The notebook app will be updated for the newly released chapters; vocabulary progress stays in the browser where you use the notebook. Importing a new EPUB does not move that progress between devices.
